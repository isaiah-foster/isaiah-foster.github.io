Projects

VisualNetwork ↗

Linux network traffic analyzer built on a small Agile team, where I did all kernel-side development. C eBPF programs on XDP (ingress) and TC (egress) hooks classify packets by protocol and address and keep counters in BPF maps. A Go userspace daemon reads the maps via a ring buffer, aggregates volume, protocol, and latency metrics, and serves them to a React dashboard through a reverse proxy.

Built with: C · Go · eBPF (XDP/TC) · libbpf · Linux · Make

R2Notary ↗

Tamper-evident audit log for Cloudflare R2 buckets. Every object change is appended to an RFC 6962 Merkle tree, published as C2SP tlog-tiles with Ed25519-signed checkpoints. A separate Go CLI verifies inclusion and consistency proofs without trusting the server, and a resumable audit flags unlogged writes, missing objects, and overwrites. Supports witness cosigning and key blinding. Runs end to end locally and passes contract tests against real R2.

Built with: TypeScript · Go · Cloudflare Workers · Durable Objects · Queues · R2

Lockdown IDE ↗

IDE for student coding exams with a Monaco editor and instructor-controlled aid levels. Exam configs are Ed25519-signed, aid levels are also enforced server-side in the LSP proxy, student activity forms a hash-chained, tamper-evident event log, and code runs in a bubblewrap sandbox with no network access.

Built with: TypeScript · React · Monaco · Fastify · SQLite · bubblewrap
